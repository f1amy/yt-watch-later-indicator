# yt-wl-indicator
Shows a small badge on any video thumbnail that is already in your Watch Later playlist (home, subscriptions, search, recommended/up-next, channels, history, playlists).

Also brings back the one-click **Watch later** button: hover a thumbnail and click the clock in its top-right corner to add the video (a check mark removes it again). It uses YouTube's own command, so you get the usual "Saved to Watch later" toast with Undo.

Install on [tampermonkey](https://www.tampermonkey.net/) by opening [ytWatchLaterIndicator.user.js](ytWatchLaterIndicator.user.js) and clicking "raw".
